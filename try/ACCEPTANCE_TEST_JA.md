# C123 無料診断版（beta） 受入テスト手順（会長用）

このファイルは、コードを読まずに**ブラウザだけ**で無料診断版を確認するための手順です。
所要時間はおよそ10分です。専門的な操作は必要ありません。

---

## 0. 事前に用意するもの

- Google Chrome または Microsoft Edge（現行版）
- このリポジトリがあるPC（テスト用データがこのPCの中に入っています）

テスト用データの場所（すべて架空の合成データで、個人情報は含まれていません）：

- 旧データ：`C:\app\C\c123-wtp-lp-repo\try\testdata\old`
- 新データ：`C:\app\C\c123-wtp-lp-repo\try\testdata\new`

> ご自身の本物のGoogle Takeoutは、この受入テストでは使わないでください。
> （個人データを使わずに全項目を確認できるように、合成データを用意してあります。）

---

## 1. ページを開く

ブラウザで次のURLを開きます。

```
https://us-account.github.io/c123-wtp-lp/try/
```

**確認すること**

- ページ上部に「無料診断版 beta」と表示されている
- 「ご利用前に必ずお読みください」の中に、次の6点がすべて書かれている
  1. 2時点分のGoogle Takeoutが必要
  2. Google側から保存地点を復元する機能ではない
  3. Google公式ツールではない
  4. 自動判定できない項目は「要確認」になる
  5. ファイルの内容は端末外へ送信しない
  6. beta版である
- 「対応ブラウザ・対応環境」の欄がある
- 「本ページはアクセス解析を使用します。お客様のファイルの内容は送信されません。」と書かれている

---

## 2. テスト1：正常なデータで診断できること／件数が正しいこと

1. 「STEP 1 前回のデータ（古い方）」の **［前回のフォルダを選ぶ］** を押します。
2. フォルダ選択の画面で `C:\app\C\c123-wtp-lp-repo\try\testdata\old` を選び、
   「アップロード」または「フォルダーの選択」を押します。
   （ブラウザが「このサイトにファイルをアップロードしますか？」と確認しますが、
   これはブラウザがフォルダを**読み取る**ための確認で、外部送信は行われません。）
3. 「選択済み：9件を読み込みました（CSV 1件）」と表示されることを確認します。
4. 「STEP 2 今回のデータ（新しい方）」の **［今回のフォルダを選ぶ］** を押し、
   `C:\app\C\c123-wtp-lp-repo\try\testdata\new` を選びます。
5. 「選択済み：8件を読み込みました（CSV 1件）」と表示されることを確認します。
6. **［無料で診断する］** ボタンを押します。

**正常時に表示されるべき件数（この4つの数字が一致すればPASS）**

| 欄 | 表示されるべき件数 |
| --- | --- |
| 今回見つからない | **3** |
| 今回増えた | **3** |
| 変更の可能性 | **2** |
| 要確認 | **1** |

その下に「差分の合計は 9 件です。」と表示されます。

---

## 3. テスト2：詳細表示が3件で止まること

テスト1の結果画面をそのまま見てください。

「差分の詳細（無料診断版は先頭3件まで）」の表に注目します。

**確認すること**

- 表の**データ行がちょうど3行**であること（見出し行「状態／前回／今回」は数えません）
- 表示される3行が次のとおりであること

| 状態 | 前回 | 今回 |
| --- | --- | --- |
| 今回見つからない | 架空公園A | — |
| 今回見つからない | 架空公園B | — |
| 今回見つからない | 架空書店 | — |

- 表のすぐ下に
  **「4件目以降の詳細は、無料診断版では表示しません。有料版で確認できます。」**
  と表示されていること

**PASSの条件**：合計9件の差分があるのに、画面に出ている詳細は3行だけであること。
4行目以降（架空ベーカリー・架空温泉・架空美術館・架空ホテル・架空レストラン・架空ラーメン店）は
**どこにも表示されません**。ページ内をどれだけスクロールしても出てこないことを確認してください。

> 画面上でさらに確認したい場合は、キーボードの `Ctrl` + `F` でページ内検索を開き、
> `架空ベーカリー` と入力してください。**「見つかりません」となればPASS**です。
> 同様に `架空温泉` `架空美術館` でも検索し、いずれも見つからないことを確認してください。

---

## 4. テスト3：同じデータ同士では0件になること（誤検出がないこと）

1. ページを再読み込みします（`F5` キー）。
2. 「STEP 1」で `C:\app\C\c123-wtp-lp-repo\try\testdata\old` を選びます。
3. 「STEP 2」でも **同じ** `C:\app\C\c123-wtp-lp-repo\try\testdata\old` を選びます。
4. **［無料で診断する］** を押します。

**正常時の表示**

| 欄 | 表示されるべき件数 |
| --- | --- |
| 今回見つからない | **0** |
| 今回増えた | **0** |
| 変更の可能性 | **0** |
| 要確認 | **0** |

- 「差分は見つかりませんでした（合計 0 件）。」と表示される
- 詳細の表には「表示する差分はありません。」の1行だけが出る
- 「4件目以降の詳細は…」の黄色い案内は**出ない**

**PASSの条件**：4つの数字がすべて 0 であること。1件でも0以外ならFAILです。

---

## 5. テスト4：BOOTHへのボタンが正しく動くこと

1. テスト1（またはテスト3）を実行して結果画面を表示します。
2. 結果の下にある **［BOOTHで有料版を見る］** ボタンを押します。

**確認すること**

- BOOTHの商品ページ `https://smallapplab.booth.pm/items/8717210` が開くこと
- 開いた商品ページが C123 の商品ページであること

---

## 6. テスト5：既存LPからの導線

1. `https://us-account.github.io/c123-wtp-lp/` を開きます。
2. ページ上部（購入ボタンの近く）に
   **「購入前に自分のデータで無料診断する」** のリンクがあることを確認します。
3. そのリンクの近くに
   「ファイルは外部送信されません」「無料版は差分詳細を先頭3件まで確認できます」
   と書かれていることを確認します。
4. リンクを押すと、無料診断ページ（`/try/`）が開くことを確認します。

## 7. 会長が確認できる項目と、実装担当が技術確認した項目

### A. 会長がブラウザだけで確認できる項目（開発者ツール不要）

| # | 項目 | 確認方法 |
| --- | --- | --- |
| A-1 | 正常なデータで診断できる | 本書 セクション2 |
| A-2 | 件数が正しい（3 / 3 / 2 / 1） | 本書 セクション2 の表 |
| A-3 | 詳細表示が3件で止まる | 本書 セクション3 |
| A-4 | 4件目以降が画面に出ない | 本書 セクション3 の `Ctrl` + `F` 検索 |
| A-5 | 同一データ同士で0件（誤検出なし） | 本書 セクション4 |
| A-6 | BOOTHへのボタンが動く | 本書 セクション5 |
| A-7 | 既存LPからの導線がある | 本書 セクション6 |
| A-8 | 必須の注意書きが画面に出ている | 本書 セクション1 |
| A-9 | 対応ブラウザ・対応環境の記載がある | 本書 セクション1 |
| A-10 | アクセス解析の明記がある | 本書 セクション1 |

### B. 実装担当が技術確認した項目（会長の操作では確認できません）

| # | 項目 | 確認方法（実装担当側） |
| --- | --- | --- |
| B-1 | 有料版と無料版で差分件数が完全に一致する | 有料版 `release-browser-v0.1.1/app.js` の計算結果と、無料診断ページの画面表示を同一データで自動比較 |
| B-2 | 4件目以降がDOMに存在しない | 診断後のページ全体のHTMLを走査し、有料版が出力する全9件のタイトルのうち、画面に出した3件以外が1件も含まれないことを確認 |
| B-3 | 4件目以降がconsoleに出ない | console出力を横取りして記録。診断中の出力は0件 |
| B-4 | 4件目以降がlocalStorage / sessionStorage / IndexedDB / URLに出ない | 診断後に各ストレージの件数とURLを確認。すべて空 |
| B-5 | CSV等のエクスポート機能が無料版のコードに存在しない | 無料版の全ファイルを検索。`csvDocument` / `htmlDocument` / `exportRows` / `Blob` / `createObjectURL` / `download` はいずれも0件 |
| B-6 | 有料機能を非表示にしただけの実装ではない | 無料版は有料版のコードを引き継がない別ビルド。診断関数は件数と最大3件しか返さず、4件目以降は関数の外へ出ない構造 |
| B-7 | 診断中のネットワーク送信が許可した4イベント以外に0件 | 診断中の全ネットワークリクエストを記録して確認 |
| B-8 | ファイル名・CSV内容・地点情報がGA4等へ送られない | 解析へ渡せるのはイベント名のみ。値を渡す引数が存在しないことをコードと実行時記録の両方で確認 |
| B-9 | 有料版ファイルと販売ZIPが未変更 | 作業前後でSHA-256を照合し一致を確認 |

## 8. 判定

セクション2〜6の表示が本書のとおりであれば **受入PASS** です。
1つでも数字や表示が異なる場合は、その画面を閉じずに実装担当へご連絡ください。
