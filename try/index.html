有料版 C123（2,980円・買い切り）

有料版のC123では、差分の全件表示と、結果のCSV / HTML保存に対応しています。このページの無料診断では、お手元の2時点のGoogle Takeoutで動作を確認できます。

BOOTHで有料版を見る

購入・決済・ダウンロードはBOOTHで行います。

ご利用前に必ずお読みください

  • 比較には2時点分のGoogle Takeout（前回の書き出しと今回の書き出し）が必要です。1つだけでは比較できません。
  • これはGoogle側から保存地点を復元する機能ではありません。手元の2つの書き出しを比べて差分を示すだけのツールです。
  • C123はGoogle公式ツールではありません。Google LLCとは関係ありません。
  • 同一地点かどうかを自動判定できない項目は「要確認」として件数に計上されます。削除や消失を断定するものではありません。
  • お客様のファイルの内容（ファイル名・地点名・住所・座標・CSVの中身）は端末外へ送信しません。アップロードも保存もしません。
  • 本ツールはbeta版です。判定結果に誤りが含まれる可能性があります。

本ページはアクセス解析を使用します。お客様のファイルの内容は送信されません。

対応ブラウザ・対応環境

  • 対応ブラウザ：Google Chrome（現行版） / Microsoft Edge（現行版）
  • 対応OS：Windows 10 / Windows 11 / macOS
  • 入力：Google Takeoutを解凍したフォルダ、またはその中の保存済みリストCSV（UTF-8）
  • フォルダ選択にはChrome / Edgeのフォルダ選択機能を使用します。Safari・Firefoxおよびスマートフォンのブラウザでは、フォルダ選択が動作しない場合があります。その場合はCSVを直接選んでください。
  • インターネット接続がなくても診断できます（アクセス解析の送信のみ行われません）。
